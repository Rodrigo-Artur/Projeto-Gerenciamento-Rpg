# Mesa do Mestre

[English](#english) | [Português](#português)

A full-stack platform for organizing and running tabletop RPG campaigns.

---

## English

### About the project

Mesa do Mestre is a campaign management platform designed to help Game Masters prepare, organize and run tabletop RPG sessions.

The application combines campaign documentation, character sheets, combat automation and real-time session tools in a single workspace.

### Main features

- Campaign, system, character, NPC and boss management
- Dedicated session dashboard
- Automated combat with initiative, HP, conditions and rounds
- Custom resources, skill macros and cooldowns
- Reusable content library and campaign packages
- World calendar and scheduled events
- NPC relationships and campaign history
- Session logs and automatic summaries
- Snapshots, comparisons and undo history
- Secure reading and editing modes
- Player screen with public combat information
- Revealable handouts, characters, locations and images
- JSON import and export
- Support for external image URLs

### Technologies

- React
- TypeScript
- JavaScript
- SQLite
- Node.js
- Vite

### Getting started

```bash
git clone YOUR_REPOSITORY_URL
cd mesa-do-mestre
npm install
npm run dev
```

Open the local address displayed in the terminal.

### Production build

```bash
npm run build
```

### Project goals

The project was created to reduce the amount of information a Game Master must manage manually during a session. It provides quick access to campaign content while automating repetitive combat and session-management tasks.

## Português

### Sobre o projeto

Mesa do Mestre é uma plataforma de gerenciamento de campanhas criada para ajudar mestres a preparar, organizar e conduzir sessões de RPG de mesa.

A aplicação reúne documentação da campanha, fichas, automação de combate e ferramentas de sessão em um único ambiente.

### Principais funcionalidades

- Gerenciamento de campanhas, sistemas, personagens, NPCs e chefes
- Painel dedicado ao uso durante a sessão
- Combate automatizado com iniciativa, PV, condições e rodadas
- Recursos personalizados, macros de habilidades e recargas
- Biblioteca reutilizável e pacotes de conteúdo
- Calendário do mundo e eventos programados
- Relações entre NPCs e histórico da campanha
- Logs e resumos automáticos das sessões
- Snapshots, comparações e histórico para desfazer alterações
- Modos seguros de leitura e edição
- Tela do jogador com informações públicas do combate
- Handouts, personagens, locais e imagens reveláveis
- Importação e exportação em JSON
- Suporte a imagens externas por URL

### Tecnologias

- React
- TypeScript
- JavaScript
- SQLite
- Node.js
- Vite

### Como executar

```bash
git clone URL_DO_SEU_REPOSITORIO
cd mesa-do-mestre
npm install
npm run dev
```

Abra o endereço local exibido no terminal.

### Gerar a versão de produção

```bash
npm run build
```

### Objetivo

O projeto foi desenvolvido para diminuir a quantidade de informações que um mestre precisa controlar manualmente durante uma sessão. Ele facilita o acesso ao conteúdo da campanha e automatiza tarefas repetitivas de combate e gerenciamento.
